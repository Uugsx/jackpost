Jackpost is een nieuwe en innovatieve API-client, gericht op het revolutioneren van de status quo die wordt vertegenwoordigd door Postman en vergelijkbare tools.

Jackpost slaat je collecties direct op in een map op je bestandssysteem. We gebruiken een platte tekst opmaaktaal, Jp, om informatie over API-verzoeken op te slaan.

Je kunt Git of elke versiebeheertool naar keuze gebruiken om samen te werken aan je API-collecties.

Jackpost is uitsluitend offline. Er zijn geen plannen om ooit cloud-synchronisatie aan Jackpost toe te voegen. We waarderen je gegevensprivacy en geloven dat deze op je apparaat moet blijven. Lees onze langetermijnvisie [hier](https://github.com/usejackpost/jackpost/discussions/269)

### Installatie

Jackpost is beschikbaar als binaire download [op onze website](https://www.usejackpost.com/downloads) voor Mac, Windows en Linux.

Je kunt Jackpost ook installeren via pakketbeheerders zoals Homebrew, Chocolatey, Scoop, Snap, Flatpak en Apt.

```sh
# Op Mac via Homebrew
brew install jackpost

# Op Windows via Chocolatey
choco install jackpost

# Op Windows via Scoop
scoop bucket add extras
scoop install jackpost

# Op Windows via winget
winget install Jackpost.Jackpost

# Op Linux via Snap
snap install jackpost

# Op Linux via Flatpak
flatpak install com.usejackpost.Jackpost

# Op Linux via Apt
sudo mkdir -p /etc/apt/keyrings
sudo apt update && sudo apt install gpg curl
curl -fsSL "https://keyserver.ubuntu.com/pks/lookup?op=get&search=0x9FA6017ECABE0266" \
  | gpg --dearmor \
  | sudo tee /etc/apt/keyrings/jackpost.gpg > /dev/null
sudo chmod 644 /etc/apt/keyrings/jackpost.gpg
echo "deb [arch=amd64 signed-by=/etc/apt/keyrings/jackpost.gpg] http://debian.usejackpost.com/ jackpost stable" \
  | sudo tee /etc/apt/sources.list.d/jackpost.list
sudo apt update && sudo apt install jackpost
```
