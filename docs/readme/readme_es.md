Jackpost es un cliente de APIs nuevo e innovador, creado con el objetivo de revolucionar el panorama actual representado por Postman y otras herramientas similares.

Jackpost almacena tus colecciones directamente en una carpeta de tu sistema de archivos. Usamos un lenguaje de marcado de texto plano, llamado Jp, para guardar información sobre las peticiones a tus APIs.

Puedes usar git o cualquier otro sistema de control de versiones que prefieras para colaborar en tus colecciones.

Jackpost funciona sin conexión a internet. No tenemos intenciones de añadir sincronización en la nube a Jackpost, en ningún momento. Valoramos tu privacidad y creemos que tus datos deben permanecer en tu dispositivo. Puedes leer nuestra visión a largo plazo [aquí](https://github.com/usejackpost/jackpost/discussions/269).

[Descarga Jackpost](https://www.usejackpost.com/downloads).

📢 Mira nuestra charla en la conferencia India FOSS 3.0 [aquí](https://www.youtube.com/watch?v=7bSMFpbcPiY).

### Instalación

Jackpost está disponible para su descarga [en nuestro sitio web](https://www.usejackpost.com/downloads) para Mac, Windows y Linux.

También puedes instalar Jackpost mediante package managers como Homebrew, Chocolatey, Scoop, Flatpak y Apt.

```sh
# En Mac con Homebrew
brew install jackpost

# En Windows con Chocolatey
choco install jackpost

# En Windows con Scoop
scoop bucket add extras
scoop install jackpost

# En Linux con Snap
snap install jackpost

# En Linux con Flatpak
flatpak install com.usejackpost.Jackpost

# En Linux con Apt
sudo mkdir -p /etc/apt/keyrings
sudo apt update && sudo apt install gpg curl
curl -fsSL "https://keyserver.ubuntu.com/pks/lookup?op=get&search=0x9FA6017ECABE0266" \
  | gpg --dearmor \
  | sudo tee /etc/apt/keyrings/jackpost.gpg > /dev/null
sudo chmod 644 /etc/apt/keyrings/jackpost.gpg
echo "deb [arch=amd64 signed-by=/etc/apt/keyrings/jackpost.gpg] http://debian.usejackpost.com/ jackpost stable" \
  | sudo tee /etc/apt/sources.list.d/jackpost.list
sudo apt update && sudo apt install jackpost
```
