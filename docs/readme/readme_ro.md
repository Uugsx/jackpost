Jackpost este un client API nou și inovativ, care vizează să revoluționeze status quo-ul reprezentat de Postman și alte instrumente similare.

Jackpost salvează colecțiile voastre direct într-o mapă din sistemul dvs. de fișiere. Folosim un limbaj de marcare cu text simplu, Jp, pentru a salva informații despre cererile API.

Puteți folosi Git sau orice altă unealtă de control al versiunii la alegere pentru a colabora la colecțiile API voastre.

Jackpost este numai offline. Nu va exista niciodată vreun plan pentru a adăuga sincronizarea cloud la Jackpost. Noi valorăm confidențialitatea datelor voastre și credem că ar trebui să rămână pe dispozitivul vostru. Citiți viziunea noastră pe termen lung [aici](https://github.com/usejackpost/jackpost/discussions/269)

📢 Priviți prezentarea noastră recentă de la India FOSS 3.0 Conference [aici](https://www.youtube.com/watch?v=7bSMFpbcPiY)

### Instalarea

Jackpost este disponibil ca descărcare binară [pe website-ul nostru](https://www.usejackpost.com/downloads) pentru Mac, Windows și Linux.

De asemenea, puteţi instala Jackpost cu un gestionar de pachete precum Homebrew, Chocolatey, Snap şi Apt.

```sh
# Pe Mac cu Homebrew
brew install jackpost

# Pe Windows cu Chocolatey
choco install jackpost

# Pe Linux cu Snap
snap install jackpost

# Pe Linux cu Apt
sudo mkdir -p /etc/apt/keyrings
sudo apt update && sudo apt install gpg curl
curl -fsSL "https://keyserver.ubuntu.com/pks/lookup?op=get&search=0x9FA6017ECABE0266" \
  | gpg --dearmor \
  | sudo tee /etc/apt/keyrings/jackpost.gpg > /dev/null
sudo chmod 644 /etc/apt/keyrings/jackpost.gpg
echo "deb [arch=amd64 signed-by=/etc/apt/keyrings/jackpost.gpg] http://debian.usejackpost.com/ jackpost stable" \
  | sudo tee /etc/apt/sources.list.d/jackpost.list
sudo apt update && sudo apt install jackpost
```
